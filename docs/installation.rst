Installation
============

PyNeuraLogic can be easily installed from PyPI repository via :code:`pip install` command.


.. tip::
    :class: empty-title

    .. code-block::

        pip install neuralogic

To use the PyTorch integration, install the package with the ``torch`` extra:

.. code-block::

    pip install "neuralogic[torch]"

Requirements
############

The PyNeuraLogic library requires :code:`Python >= 3.10` and :code:`Java >= 1.8` to be installed.

If you plan to use NeuraLogic as a PyTorch function, install the package with the ``torch`` extra as shown above.

In case you want to use visualization provided in the library, it is required to have `Graphviz <https://graphviz.org/download/>`_ installed.
